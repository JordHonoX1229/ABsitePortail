Pages de vérification (captcha)

Quand une page affiche un captcha, un bandeau vous prévient dans le navigateur distant : la vérification peut prendre un peu de temps à cause de la version avancée de détection de bots. Patientez sans recharger la page.

Le bandeau est affiché par une extension installée dans le navigateur distant (voir GUIDE.md).

Aide

Comment ça marche

  1. Vous vous inscrivez, l'administrateur valide votre compte.
  2. Dans « Mon accès », vous ouvrez le navigateur distant dans un nouvel onglet.
  3. Vous saisissez l'identifiant et le mot de passe du navigateur, puis vous naviguez.

Ça ne s'affiche pas ?

Une erreur 502 ou 404 signifie que le serveur du navigateur est éteint ou en train de démarrer. Le démarrage prend plusieurs minutes. Si ça persiste, prévenez l'administrateur.

Pour l'administrateur

Le navigateur n'est disponible que tant que votre codespace est démarré (il s'arrête après 30 minutes d'inactivité). Après chaque démarrage : relancez Chromium si besoin, rendez le port 6901 public et vérifiez que l'adresse enregistrée dans l'administration est toujours la bonne.
